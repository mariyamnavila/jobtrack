# JobTrack

**JobTrack** is a frontend web app to **apply for jobs and manage applications**. Built with **React**, **TailwindCSS**, and **DaisyUI**, it features smooth UI interactions and real-time notifications.  


## Features

- Apply for jobs  
- Delete job applications  
- Animated UI with **GSAP**  
- Notifications via **React Toaster**  
- Client-side routing with **React Router**  


## Tech Stack

React | TailwindCSS | DaisyUI | GSAP | React Router | React Toaster | Vite | Firebase

## Quick Setup

Follow these steps to run JobTrack locally:

1. **Clone the repository**  
```bash
git clone https://github.com/mariyamnavila/jobtrack.git
cd jobtrack
```
2. **Install dependencies**
```
npm install
```
3. **Start the development server**
```
npm run dev
```
4. **Open the app in your browser**

Visit the URL shown in your terminal (usually http://localhost:5173) to see JobTrack in action.
